# Teamdocs

In deze map vind je de documentatie die specifiek is voor jouw team. Denk hierbij aan de teamrollen, teamafspraken en de teamplanning. Hiervan wordt geen website gegenereerd, alleen jullie en de docenten kunnen deze documenten lezen.

Belangrijk is wel om samen een goede structuur te kiezen voor deze documenten. Wij adviseren om markdown te gebruiken voor deze documenten.
