# Product Website

Welkom op de product website van jullie project. In deze omgeving kan je documentatie plaatsen die jullie project betreft en best gezien mag worden door anderen. Documentatie kan je schrijven met markdown, voeg vooral ook plaatjes toe om de documentatie meer duidelijk te maken.

!!! warning "Let op"

    Alles wat in deze `/docs` folder wordt geplaatst wordt automatisch op de website getoond. Zorg er dus voor dat je geen gevoelige informatie deelt. Deze website is publiek toegankelijk.
